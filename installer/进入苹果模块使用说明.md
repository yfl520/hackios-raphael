# 红米双系统：从 Android 进入 iOS

[简体中文](进入苹果模块使用说明.md) · [English](MODULE-GUIDE.en.md)

酷安：你说喜欢是装的

本模块配套「红米双系统一键安装包（蜂窝上网版）」，适用于已完成持久化双系统安装的 Redmi K20 Pro／raphael。支持安装包允许的自选 iOS 容量，Android 必须已有可用的 root。

## 安装或覆盖更新旧模块

1. 先确认手机已有配套双系统。只安装此模块不会安装 iOS；若只有旧版双系统，先在电脑运行配套一键包的「一键更新.bat」。
2. 把「红米双系统进入苹果模块（蜂窝上网版）.zip」复制到手机，保留 ZIP，不要解压。
3. 打开 Android 的 Magisk、KernelSU 或 KernelSU Next 管理器，进入「模块 → 从本地安装」，选择该 ZIP。不要在 TWRP 中刷此模块。
4. 等待三个检查步骤通过。安装过程本身不会请求重启或切换系统。
5. 如果已安装旧的「HackiOS · 进入 iOS」，直接安装新版覆盖即可，两版使用相同模块 ID。确认模块开关已启用。
6. 按管理器提示正常重启 Android 一次，使模块更新生效。此时正常进入 Android，不需要按音量键。
7. 再次打开管理器的模块列表，找到「红米双系统 · 进入 iOS」。

## 一键进入 iOS

1. 在 Android 保存正在编辑的文件，关闭不需要的操作。
2. 到 root 管理器的模块列表，点击本模块卡片上的「操作／Action」。
3. 等待引导器、启动资源、数据卷检查结束。检查通过后会请求重启到 iOS，期间不需要再按音量上。
4. 等待经过引导画面和苹果标志，进入 iOS。

模块不会在 Android 开机时自动切换。正常按电源键开机仍进入 Android；不使用模块时，也可以正常关机后按电源＋音量上进入已有 iOS 入口。

## 只检查，不重启

在 Android 已取得 root 的终端中运行：

```
sh /data/adb/modules/hackios_raphael_switch/action.sh --check
```

这个命令只读取检查结果。成功时显示「只读检查结束，没有请求重启」。要从终端执行切换，先保存 Android 中的工作，再运行相同命令并去掉 --check。

如果管理器没有「操作」按钮，可使用上述 root 终端方式；终端本身也需要获得 root 授权。

## 检查未通过怎么办

| 提示 | 处理方法 |
| --- | --- |
| 需要 root | 检查 root 管理器本身是否正常；普通未授权终端不能执行 |
| Android 未完成开机 | 等到桌面可正常操作后再运行 |
| 找不到 darwin | 确认已完成配套双系统安装，不要仅安装模块 |
| recovery 引导器不匹配 | 从手机正常关机进入 FASTBOOT，电脑运行配套包的「一键更新.bat」，完成后回 Android 再试 |
| 启动资源版本或布局不匹配 | 使用与本模块配套的一键包保留数据更新，不要修改 target.conf 绕过检查 |
| 数据卷未初始化或容量不一致 | 保留原安装目录和 session-private，记录完整错误；不要盲目重复首次安装或格式化 |
| 模块已停用或等待卸载 | 检查管理器内的启用状态，按提示重启 Android 完成变更 |

模块按实际容量检查，不要求固定为 20 GiB。它仍校验配套引导器的完整指纹，避免把 TWRP 或官方 recovery 当作 iOS 启动入口。

## 返回 Android 与卸载

从 iOS 打开「设置 → 通用 → 关机」，正常关机后按电源键开机进入 Android。

需要卸载模块时，在 Android 的 root 管理器内卸载并按提示重启即可。卸载模块只移除这个快捷入口，完整删除 iOS 仍使用电脑安装包的选项 9。
