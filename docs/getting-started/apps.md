# 应用安装

[简体中文](apps.md) · [English](apps.en.md)

## 巨魔安装

先按 [完整包使用说明](../../installer/使用说明.md) 安装并打开 TrollStore。Safari 分享和本地文件导入尚未修复，可使用巨魔的「通过 URL 安装」。

## 局域网 URL

1. 手机与电脑连接到能够互相访问的局域网。
2. 在完整包里运行 `IPA链接安装.bat`，选择电脑上已下载的 IPA。
3. 若有多个可用网卡，选择手机能访问的局域网地址。
4. 将工具显示的完整链接填入巨魔的「通过 URL 安装」，确认后保持下载服务窗口开启。
5. 等待传输和手机端安装完成。电脑端显示传输完成，不等于巨魔已经安装成功。

工具使用递增编号区分文件，并按文件内容检查身份。换应用后使用工具当前显示的新链接；不要修改链接或继续使用过期链接。

若超时，先在手机 Safari 打开同一链接，检查电脑防火墙、网卡选择及路由器客户端隔离。手机与电脑仅处于相同网段，不代表两者一定可以互相访问。

源代码和独立运行要求见 [安装器源码](../../installer/README.md)。更详细的操作与恢复步骤见 [完整包教程](../../installer/使用说明.md)。
