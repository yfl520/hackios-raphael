# 手机与安装包

源码仓库与完整安装包用途不同：本仓库用于构建和开发；刷机需要包含匹配镜像、TWRP、工具及文件清单的完整安装包。GitHub 的 **Download ZIP** 下载的是源码，不能作为完整刷机包运行。

## 安装前

1. 核对 [机型与功能支持](../../devices/raphael/README.md)。不要将本机型镜像刷入其他设备。
2. 准备已解锁 bootloader 的手机、Windows 电脑、USB 数据线和匹配的完整安装包。
3. 按包内说明安装驱动，准备与当前静态／动态分区布局匹配的 recovery。
4. 先读完整教程里的数据清除、容量选择、恢复与救砖部分，再执行安装。

## 操作入口

[完整包使用说明](../../installer/使用说明.md) 涵盖安装、升级、切换系统、续装、移除、巨魔安装和线刷恢复。教程中的工具与镜像路径相对于完整包，不会在源码仓库中自动存在。

Android 切换模块的安装与使用见 [模块说明](../../android-module/使用说明.md)，必须与完整包的资源几何及哈希匹配。

## 无线数据

安装器尝试从本机 root recovery 读取 `modemst1`、`modemst2`、`fsg`、`fsc`，不要求 Android root。提取失败可继续，但不能保证缺少有效本机校准数据时 Wi-Fi 或蜂窝可用。不要使用他人的 NV。

构建与自组装镜像见 [Linux 构建方法](../BUILD.md)。
